Это 2D-пиксельная адвенчура с элементами визуальной новеллы, которая еще даже не обрела облик, но уже хранит в себе базовые механики для простой в прохождении игры.

Пока-что могу сказать, что сделал проект лично для себя, но сделал публичным, чтобы можно было ознакомиться с кодом и по возможности получить живую оценку архитектуре и скриптам.

Скрипты написаны на самых простых технологиях, Input Manager, ScriptableObjects, Singleton и другие более мелкие системы.
